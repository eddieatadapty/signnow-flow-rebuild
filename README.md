# SignNow Growth Audit

**Live → https://eddieatadapty.github.io/signnow-flow-rebuild/**

Five ideas to turn more SignNow users into subscribers, each built into a clickable version of SignNow's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Let them sign something before the price | +10–20% CR to purchase |
| 02 | Ask one thing, and use it on the paywall | +10–15% CR to purchase |
| 03 | Ask for the account after the first signature | +5–10% CR · ARPU +10–17% |
| 04 | Make the yearly saving impossible to miss | +5–15% CR · ARPU +10–15% |
| 05 | Put your proof next to the button | +5–10% CR to purchase |

Every price, rating and feature comes from SignNow's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for SignNow. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
